データ移行ツール

旧 memories テーブルの1行JSONを、新しいテーブル群へ移します。

先にやっておくこと
1. sql/01_schema.sql を Supabase の SQL Editor で実行
2. ふたりの auth.users の id を space_members に手で入れる
3. このページを本番と同じドメインで開く

このツールは何度実行しても二重登録されません（移行済みの印を見ます）。 旧 memories テーブルは消さないので、失敗してもやり直せます。

1. ログイン

2. 中身を確認する（書き込みません）

3. 移行を実行する
